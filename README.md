# Selam! Ben Gül Eda Kaya 👋

### 🎓 Hakkımda
Ben **Recep Tayyip Erdoğan Üniversitesi**'nde Bilgisayar Mühendisliği 3. sınıf öğrencisiyim. Aynı zamanda Anadolu Üniversitesi'nde Bilgisayar Programcılığı eğitimime devam ediyorum. Hem yazılım geliştirme hem de donanım tabanlı projelere (IoT/Otomasyon) büyük bir tutkum var.

- 🔭 **Şu an ne üzerinde çalışıyorum:** Java ve Spring Boot ile backend projeleri geliştiriyorum.
- 🌱 **Neler öğreniyorum:** Yapay zeka frameworkleri (TensorFlow & PyTorch) ve React.
- 🚀 **Önemli Başarı:** TÜBİTAK 2209-A kapsamında "Akıllı Bitki Yetiştirme Kapsülü" projesini geliştirdim.
- 🏛 **Topluluk:** AI&SEC (Yapay Zeka ve Siber Güvenlik Topluluğu) Finans Koordinatörüyüm.
